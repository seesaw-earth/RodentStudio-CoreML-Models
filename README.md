# RodentStudio Core ML Models

Two Core ML models used by the RodentStudio macOS application.

## Models

- MousePose6_960_int8.mlpackage
- CylinderMousePoseV2.mlpackage

## Purpose

Local rodent pose estimation and behavioral analysis.

## Usage

The models are provided in Apple's Core ML format.
Keep each .mlpackage directory intact when copying it into an Xcode project.

## Notes

Model version, training provenance, and redistribution licenses should be documented before public release.
